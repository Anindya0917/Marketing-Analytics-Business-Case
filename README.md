# Marketing Analytics Business Case

An end-to-end **Marketing Analytics project** focused on analyzing customer journeys, engagement, and customer reviews to generate actionable business insights using **SQL, Python, and Power BI**.

## 📌 Project Overview

This project analyzes customer and marketing data to understand customer behavior, engagement patterns, product performance, and customer sentiment.

The workflow combines **SQL-based data preparation and analysis**, **Python sentiment analysis**, and an interactive **Power BI dashboard** to transform raw data into stakeholder-focused insights.

## 🎯 Business Objectives

* Analyze customer journeys and engagement patterns.
* Identify and handle duplicate and missing data.
* Standardize and transform raw datasets for analysis.
* Analyze customer reviews and sentiment.
* Identify trends in customer satisfaction and product performance.
* Develop interactive KPIs and dashboards for business decision-making.

## 🛠️ Tools & Technologies

* **SQL** — Data cleaning, transformation, modelling, and analysis
* **Python** — Customer review processing and sentiment analysis
* **VADER** — Sentiment analysis of customer reviews
* **Power BI** — Interactive dashboards and KPI visualization
* **CSV / SQL datasets** — Data storage and analysis

## 🔄 Project Workflow

### 1. Data Preparation & SQL Analysis

SQL was used to clean, transform, and structure the datasets, including:

* Duplicate record handling
* Missing-value treatment
* Data standardization
* Customer and product dimension creation
* Customer journey analysis
* Customer review analysis
* Engagement data analysis

### 2. Customer Sentiment Analysis

Python was used to process customer reviews and perform sentiment analysis using **VADER**.

The analysis categorizes customer feedback into sentiment groups and helps identify patterns in customer satisfaction.

### 3. Power BI Dashboard

The processed data was used to create an interactive Power BI dashboard for monitoring key business metrics.

The dashboard focuses on:

* Customer KPIs
* Engagement metrics
* Review and sentiment trends
* Product/customer performance
* Stakeholder-focused visual insights

## 📊 Key Analysis Areas

| Area             | Analysis                                           |
| ---------------- | -------------------------------------------------- |
| Customer Journey | Customer behavior and journey patterns             |
| Engagement       | Engagement trends and performance                  |
| Customer Reviews | Review distribution and patterns                   |
